🛠️ 从案例到 SOP：三步落地

第一步：立即冻结差店配置（本周）

涉及：麦颂KTV 2家、北京酒吧4家、青灯酒吧、巴黎印象等

  • 麦颂KTV：停发智能手表 + 盲盒，替换为 东莞至尊同款 → 成本 ¥103 → ¥1.00（103倍）
  • 北京 O club/液店/Fm调频/木星/K先生：停发京东卡 + ¥188/88红包，替换为 红馆同款 → 成本 ¥61-71 → ¥1-2（30-70倍）
  • 青灯酒吧：停发 Mate Pad + ¥520红包，替换为 BUTTERFLY 同款 → 成本 ¥40 → ¥1（40倍）
↳ 参考案例：东莞至尊（纯¥1红包，¥0.90/scan）、红馆（4种小额，¥0.91/scan）

第二步：事业二部奖品池标准化（本周启动）

二部每奖面值 ¥10.50 = 一部 ¥4.21 的 2.5倍。256家门店需统一配置。

  • 强制设定奖品层级预算：T1（≤¥3）占 ≥70% · T2（¥3-10）≤20% · T3（¥10-50）≤8% · T4-T5（¥50+）≤2%
  • 排查二部是否存在独立奖品池（高面值红包比例偏高）
  • 对标一部 BUTTERFLY 配置：¥0.5 / ¥0.88 / ¥1.88 / ¥6.88 / ¥8.8 五档
↳ 参考案例：成都 BUTTERFLY（5档小额红包，¥0.92/scan，4,692次扫码验证）

第三步：推广标准模板 + A/B 测试（本月试点）

选 10-20 家差店切换到模板，观察 1 个月扫码量变化。

  • 模板A（极简）：纯 ¥1 红包，中奖率 80-100% → 预期 ¥0.80-1.00/scan（参考：东莞至尊、T58）
  • 模板B（分层）：¥0.5(40%) + ¥1.8(30%) + ¥2.8(15%) + ¥6.8(10%) + ¥8.8(5%) → 预期 ¥1.0-1.5/scan（参考：BUTTERFLY、红馆）
  • 1个月后对比试点店 vs 未试点店的扫码量增长和成本变化
↳ 已验证：4家好店 cost_per_scan 均 ≤ ¥1.00，合计 7,077 次扫码，总成本 ¥6,536
